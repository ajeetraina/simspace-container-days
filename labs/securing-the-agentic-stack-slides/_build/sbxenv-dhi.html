CAPACITY

An environment file describes the whole sandbox

# sbxenv.yaml — committed to the repo
schemaVersion: "1"
name: product-catalog
agent: claude
workspace: .
kits:
  - git+…/dhi-mixin   # pins DHI, denies 3rd-party
secrets:
  dhi-mcp-pat:
    ref: op://Engineering/DockerHub/pat
    snapshot: true
AgentWhich harness the sandbox runs
WorkspaceThe project folder the agent can see
KitsThe dhi-mixin pins DHI and denies 3rd-party registries — tools, credentials, and network rules in one artifact
SecretsA source, not a value — the Docker Hub PAT resolved on each host, never committed
START IT WITH sbx env run · EXPERIMENTAL, FORMAT MAY CHANGE
